# ROADMAP

This roadmap outlines short-term milestones and longer-term goals for TrustOS development.

## Short-term (0–3 months)

- Stabilize Core API and Living Ledger schema.
- Implement basic SHAPE approval UI and workflows.
- Harden Runtime Adapters for Wasmer and container execution.
- Expand TABS to cover missing adversarial tests and standardize output.

## Mid-term (3–9 months)

- Add Tenki runtime adapter and integrate verifiable execution receipts.
- Implement AIRI-DNA production and verification tooling.
- Build automated CI workflows for TABS reporting and ledger validation.

## Long-term (9–18 months)

- Federation support for Living Ledger replication across organizations.
- Policy DSL and sophisticated governance rules engine.
- Formal verification and external audits of TABS and Governance Engine.

## Priorities

1. Evidence and immutability guarantees
2. Human-in-the-loop approval ergonomics
3. Threat modeling and adversarial hardening
