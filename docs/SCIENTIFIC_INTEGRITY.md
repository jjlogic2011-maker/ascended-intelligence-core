## 1. Core Prohibition

Quantum mechanics does **not** prove consciousness, spiritual phenomena, or universal frequency-based healing.  
No module, endpoint, UI label, or documentation may state or imply otherwise.

## 2. Evidence Classification (mandatory)

Every scientific claim must be labeled with exactly one of:

| Label | Meaning |
|-------|---------|
| **ESTABLISHED** | Strong, reproducible evidence from multiple independent sources |
| **SUPPORTED** | Credible evidence with meaningful limitations |
| **PRELIMINARY** | Early findings requiring further replication |
| **HYPOTHESIS** | Scientifically testable but unverified |
| **SPECULATIVE** | Insufficient evidence or no established test |

## 3. Experiment Documentation Requirements

For every experiment the system records:

- Hypothesis
- Variables and controls
- Sample size or simulation repetitions
- Measurement / computation method
- Statistical analysis and confidence intervals
- Alternative explanations
- Limitations
- Exact reproduction instructions
- Evidence classification of any interpretive claim

Negative and null findings are valid results and must not be suppressed.

## 4. Simulation vs. Physical Reality

- All quantum circuits in this laboratory are **classical numerical simulations** (Monte-Carlo or state-vector) unless real hardware access is explicitly approved and configured.
- Resonance and photonic modules generate and analyse **synthetic numerical signals**. They do not measure physical hardware unless a calibrated instrument is attached and declared.
- EEG modules process only **public, properly licensed datasets**. No claim of “consciousness detection” is permitted.
